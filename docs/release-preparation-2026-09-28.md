# 集成版发布准备与验收

本轮在 `697f2e3` 的统一集成版本上补齐前端和采购后台。Solidity、部署 ABI、编译参数与产物摘要保持一致；合约产物来源为 `8c5598cf44fe8fb6174969eba12b3baa13f7942b`，摘要为 `0x7617c81d718e2127be6b1878abad81d7a3c8bf9c4f8cb35bf85755e42df049d7`。实际发布源码提交由发布清单另行固定，不能将它和合约源码提交混为一谈。

## 本轮完成的内容

- 钱包保留扩展和钱包内置浏览器入口，新增按需加载的 WalletConnect 扫码代码。未提供 Project ID 时隐藏扫码入口。数值形式的 chainId 只在 WalletConnect 边界转换，不放宽金额解析。取消、迟到批准、重连与未决交易恢复均保留身份隔离。
- 预算项目补齐综合日产能参考、品牌分享与独立分享落地页、中英文页面、逐笔采购队列。展示金额保留三位小数，精确值用于预览和合约调用。
- 采购队列先检查完整官网候选，再考虑已验证的 Firsto 报价。每台分为创建空子池和父项目合约购买两笔；持久记录每一步，结果不明时停止并恢复，不能以重复点击重发。
- 官网采购不再相信报价快照中的有效标记。单机、预算项目和 keeper 共用固定代码哈希的 Multicall3，在同一 BSC 区块读取完整挂单范围。官网扫描错误或覆盖不完整时，不授权 Firsto 回退。
- 耗时扫描通过只读后台任务和两秒轮询完成，最多 60 秒；每次查询绑定项目、区块号与区块哈希。超过区块新鲜度限制或发生重组，要求重新预览。该过程在交易意图和钱包 nonce 保留之前完成。
- 新增独立 Linux 部署台的发布包、配置和回滚模板；现有网站、旧日志、旧索引与 keeper 不迁入新进程。

## 实测范围和保留条件

单机官网读取实测在 BSC 固定区块 `124447465` 核对 21,016 条历史挂单，耗时 29.44 秒；这不是普通用户认购或买入按钮的等待时间。外部 RPC、市场内容和网络变化可能导致扫描停止，不能把一次测速当作服务保证。

首次部署入口只提供新 16 笔合约图的部署与日志。真实链上部署、旧工厂暂停、公共清单导出、新产品与索引启用、小额成交验收仍按 [部署与测试入口](RELEASE_V2_START_HERE.md) 执行。Firsto 原生页面出售继续遵守已确认的严格结清限制。

WalletConnect 仍需网站自己的公开 Project ID 和真机配对验收；本轮测试不代替真实手机钱包连接。没有使用任何私钥、助记词或真实钱包签名进行验证。
