# 固定 BNB 预算、一个项目购买多台矿机

2026-09-27 用户已确认：先确定一个 BNB 募集目标，达标后在预算内尽量购买多台合格矿机；这些矿机共同归属一个项目的 100 份，收益按份额分配。之前的单机项目与部署继续按原规则运行。

## 当前实现状态

`deploy/scripts/budget-acquisition.mjs` 是**只读选机规划器**，不创建项目、不动用钱包、不发购机交易。输入必须是同一区块、覆盖完整且不超过五分钟的已核验候选。它按官网市场价格升序先选，再选可执行的 Firsto 签名挂单；相同 NFT 只入选一次，单台成本不得超过该矿机的独立价格上限。Firsto 买方手续费已经包含在其成本中。官网采购服务费按已购官网矿机价格的 1% 从未使用预算里扣，剩余可退金额按 100 份分配；可退余额不足时，不为了收费而挤占购机款。计算全程使用整数 Wei。

`deploy/scripts/budget-official-discovery.mjs` 补齐官网市场的只读候选发现：读取官方快照，枚举快照后新挂单，在同一个 BSC 区块重查两种官方矿机的挂单、`listingFor`、NFT 持有人及 Mining 状态，并在结束时重验区块哈希。有效纯验证矿机按真实链上挂单价排序；漏单过多、来源滞后、RPC 错误或重组均失败，不把部分扫描结果称为“最低价”。它要求建池时已审阅的单台绝对价格上限与每单位验证权重上限；上限不是募集总额。

Firsto 全量候选扫描及每笔签名订单的同区块可执行性校验尚未接到多机规划器，因而现阶段只有官网发现结果可作为完整的官方市场输入。不能把 Firsto 的一页低价列表当作全量最低价覆盖，也不能用网页估算触发采购。

**当前合约不能执行这份计划。** `PoolVault` 在第一台 NFT 购入后进入 `Active` 并结算全部余额；NFT 回调、矿币领取、出售与 Factory 的唯一性登记均绑定单台 `circuits/circuitId`。当前 `forge build --sizes` 显示 `PoolFactory` 运行时代码 24,534 字节，距 24,576 上限仅 42 字节；`PoolVault` 24,512 字节，仅余 64 字节。多机功能需要独立合约体系或经审计的模块化重构，不能在旧合约追加几个入口后直接升级。

## 上链规则

1. 募集目标在建池时固定并可被 100 整除；任一钱包可购买 1–100 份。达标后立刻开放逐台采购，募集预算、单台已付价格、矿机列表及未花余额均为链上状态。
2. 选机服务从官网完整市场快照开始，核对同一区块的有效订单、当前 NFT 持有人、挖矿中、非最优、纯验证权重及跨项目唯一性；官网候选无法覆盖预算时才考虑 Firsto 可执行的签名订单。列表排序是**所核验市场快照中的最低价**，不是对交易执行时全市场最低价的链上证明。页面须显示快照区块与时间。
3. 运营 keeper 对每台矿机单独发交易：重新核对订单、价格、卖家、矿机身份与质量、单台参考价格上限、总预算余额、来源手续费及唯一性，再付款和验收 NFT。挂单消失或涨价时跳过该候选，重新规划；任何失败交易原子回滚，不消耗募集余额。采购入口只给链上 operator/keeper，防止卖家自行把高价矿机塞进项目。
4. 每笔交易只处理一台矿机；矿机清单、收益归集、索引和前端按页处理。`n` 不设置业务上的固定台数，但不得让一笔交易随矿机数增长而变得不可执行。
5. 购机期限结束后，若至少买到一台则项目进入运行状态，未用预算扣除经确认的官网采购服务费后，按募集时的份额归属退回。若一台也未购成，则全额退回。任何人可完成结算；结算不能在期限内被运营方提前终止以逃避继续采购。
6. 每台矿机单独发起挖矿收益领取，BEM 先进入项目合约，再统一按共享 100 份记账；持有人本人随时领取。整机出售须指定具体矿机并经链上投票，价格低于该台实际购价时至少 60 份赞成，同时满足现行参与地址门槛；出售前严格结清该台待领收益。单台出售收 1% 平台费，无销毁。出售所得按当时份额直接记账；全部矿机售完项目关闭。
7. 份额转让和市场成交在采购未结算及出售表决期间冻结。现有份额市场对新项目的支持必须依据新合约的真实权限、锁仓、转移和奖励记账接口重新验收。

## 接口及发布边界

- 新的多机 Factory/Beacon/Vault 必须沿用 48 小时升级延迟、单钱包治理路径，并与现有 Factory 的矿机唯一性登记实现跨项目一致性。旧 Factory 和新 Factory 互不知晓的独立登记不能上线。
- 后端保存按 `chainId + Factory + project` 定位的项目、候选快照、报价版本、交易意图、回执与索引状态；浏览器缓存不是资金或订单真源。钱包只确认精确的单笔交易，不把离线排序结果当链上授权。
- 新合约的源码、产物、ABI、部署清单和运行时代码摘要必须一致。主网升级与采购由用户钱包按既有治理步骤签署；只读规划器的通过测试不能视为主网多机功能已部署。

## 必须通过的验收

- 两个钱包同时买最后一份、同一钱包买满 100 份；并发 keeper 购买同一 NFT、不同市场同一 NFT、旧项目和新项目抢同一 NFT。
- 报价从最低变高、卖家撤单、矿机停挖、任务或权重变化、Firsto 签名/费率/nonce 变化、官方市场优先顺序、单台价格与总预算上限。
- 零台、部分、全部采购成功；逐台领取失败但其他矿机仍可收矿币；项目余款、服务费、售出款和矿币守恒。
- 份额转移前后产出归属、出售投票快照、低于该台成本的 60 份门槛、结清失败不转 NFT、售完最后一台关闭项目。
